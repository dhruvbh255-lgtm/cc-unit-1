# Coin Change Problem Using Dynamic Programming

## 1. Aim

Given an integer array `coins` representing different coin denominations and an integer `amount`, find the fewest number of coins required to make up the given amount.

Each coin denomination can be used unlimited times. If the amount cannot be formed using the given coins, return `-1`.

## 2. Problem Statement

The Coin Change Problem is a classic Dynamic Programming problem. The objective is to find the minimum number of coins needed to make a particular amount using the available coin denominations.

**Example:**

Input:
```text
coins = [1, 2, 5]
amount = 11
```

Output:
```text
3
```

Explanation:

11 = 5 + 5 + 1

Therefore, the minimum number of coins required is 3.

## 4. Theory

Dynamic Programming (DP) is an algorithmic technique used to solve complex problems by dividing them into smaller overlapping subproblems.

In the Coin Change problem, we use a DP array where:

`dp[i]` represents the minimum number of coins required to make amount `i`.

Initially:
- `dp[0] = 0`, because zero coins are required to make amount zero.
- All other DP values are initialized to `amount + 1`, representing an initially impossible amount.

For every amount, we check all available coins and update the minimum number of coins required.

## 5. Algorithm

1. Start the program.
2. Input the coin denominations and target amount.
3. Create a DP array of size `amount + 1`.
4. Initialize all elements with `amount + 1`.
5. Set `dp[0] = 0`.
6. Iterate from 1 to the target amount.
7. Check every available coin.
8. If the current amount is greater than or equal to the coin value, update the DP array.
9. If the target amount cannot be formed, return -1.
10. Otherwise, return the minimum number of coins.
11. Stop.

## 6. Pseudocode

```text
START

INPUT coins and amount

CREATE dp array of size amount + 1

INITIALIZE all elements with amount + 1

SET dp[0] = 0

FOR i = 1 TO amount

    FOR each coin IN coins

        IF i >= coin

            dp[i] = MIN(dp[i], dp[i - coin] + 1)

        END IF

    END FOR

END FOR

IF dp[amount] > amount

    RETURN -1

ELSE

    RETURN dp[amount]

END IF

STOP
```

## 7. C++ Implementation

**File: C++/coin_change.cpp**

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {

        vector<int> dp(amount + 1, amount + 1);

        dp[0] = 0;

        for (int i = 1; i <= amount; i++) {

            for (int coin : coins) {

                if (i >= coin) {
                    dp[i] = min(dp[i], dp[i - coin] + 1);
                }

            }
        }

        if (dp[amount] > amount)
            return -1;

        return dp[amount];
    }
};

int main() {

    vector<int> coins = {1, 2, 5};
    int amount = 11;

    Solution obj;

    cout << "Minimum coins required: "
         << obj.coinChange(coins, amount);

    return 0;
}
```

## 8. Java Implementation

**File: Java/CoinChange.java**

```java
import java.util.Arrays;

class CoinChange {

    public int coinChange(int[] coins, int amount) {

        int[] dp = new int[amount + 1];

        Arrays.fill(dp, amount + 1);

        dp[0] = 0;

        for (int i = 1; i <= amount; i++) {

            for (int coin : coins) {

                if (i >= coin) {
                    dp[i] = Math.min(dp[i],
                                     dp[i - coin] + 1);
                }
            }
        }

        return dp[amount] > amount ? -1 : dp[amount];
    }

    public static void main(String[] args) {

        int[] coins = {1, 2, 5};
        int amount = 11;

        CoinChange obj = new CoinChange();

        System.out.println("Minimum coins required: "
                + obj.coinChange(coins, amount));
    }
}
```

## 9. Python Implementation

**File: Python/coin_change.py**

```python
def coin_change(coins, amount):

    dp = [amount + 1] * (amount + 1)

    dp[0] = 0

    for i in range(1, amount + 1):

        for coin in coins:

            if i >= coin:
                dp[i] = min(dp[i], dp[i - coin] + 1)

    if dp[amount] > amount:
        return -1

    return dp[amount]


coins = [1, 2, 5]
amount = 11

print("Minimum coins required:", coin_change(coins, amount))
```
